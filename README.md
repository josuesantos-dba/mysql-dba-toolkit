## Sobre o Projeto
Conjunto de scripts desenvolvidos para 
facilitar o dia a dia de um DBA MySQL 8.0,
cobrindo as principais atividades de 
administração de banco de dados.

## Estrutura

### 📁 backup/
| Script | Descrição |
|--------|-----------|
| `backup_automatico.sh` | Backup completo com logs |
| `restore.sh` | Restauração de backups |

### 📁 monitoring/
| Script | Descrição |
|--------|-----------|
| `queries_lentas.sql` | Top 10 queries mais lentas |
| `verificar_replicacao.sql` | Status da replicação |
| `verificar_locks.sql` | Locks e deadlocks |

### 📁 security/
| Script | Descrição |
|--------|-----------|
| `criar_usuarios.sql` | Usuários com boas práticas |
| `auditoria.sql` | Monitoramento de acessos |
